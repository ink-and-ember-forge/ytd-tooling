Think of a magazine spread: a photo on one page, the story on the other. This block is that layout, with the photo on the left by default.

Flip the layout

The Layout option switches the media to the right. The HTML stays in the same order either way; the change is made in CSS, so the text is always read after the media by screen readers.

Mobile

On phones the two columns stack, media first, and the image is shown at 3:2 and centred.

Buttons in the text column

Build buttons on the Buttons tab, then paste their HTML into the text column. Inside a two-column layout they automatically become full width and stack with a gap.
