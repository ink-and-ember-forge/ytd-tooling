The bit of writing that greets the reader right after the summary box — one editor, write it exactly like any other rich text field. The only special thing about this block is what happens automatically to whatever paragraph comes first.

Write normally — the sizing takes care of itself

You don't tell the tool which paragraph is the "opening" one, and there's no separate box for it. When you hit Generate, the tool looks at your finished content and finds the very first paragraph, wherever it is, and marks it:

<p class="hero-text__intro">Your opening sentence.</p>
<p>Everything else, at normal size.</p>

The size (1.25em, a quarter bigger than normal text) lives on that hero-text__intro class in the CSS, not on the text itself — so it's always applied to whatever the first paragraph turns out to be, structurally guaranteed, rather than depending on someone remembering to size it themselves every time they write one of these.

Everything else

This is the exact same rich text editor used elsewhere in the tool (headings, bold, italic, lists, links) — full flexibility. The only thing that's different about the output is that one added class on the first paragraph.
