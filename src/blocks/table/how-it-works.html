In 30 seconds: type your table into the grid, add rows and columns as you need them, choose light or striped rows, and give it a caption. It works on a phone: a wide table scrolls sideways inside its own box.

The grid

Each box is a cell. + Add row and + Add column add to the end; the × beside a row and above a column removes it. Empty rows at the bottom and empty columns on the right are left out of the page.

Headers

Tick The first row is a header for column titles, and The first column is a header when each row starts with a label (a name, a year). They are real header cells, so a screen reader reads "Band 5, Preceptorship" with each value.

Caption

Say what the table is. It is shown above the table and it is the name a screen reader gives the scrolling box. The tab warns you if it is empty.

Light or striped

Light has a themed header and thin lines between rows. Striped also tints every other row in the theme's pale colour, which helps the eye on wide tables.

Deep dive: the code 
<div class="table-scroll" role="region" aria-label="Caption" tabindex="0">
  <table class="table--striped">
    <caption>Caption</caption>
    <thead><tr><th scope="col">…</th></tr></thead>
    <tbody><tr><td>…</td></tr></tbody>
  </table>
</div>

The box is focusable (tabindex="0") and named (role="region" with aria-label) so someone using only a keyboard can scroll it. Any plain <table> in the content column gets the same look from the base CSS; wrap it in this box to make it scroll.
