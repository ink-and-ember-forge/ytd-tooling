The simplest block here — a row of "go do this" buttons, like "Sign the pledge" or "Download the guide".

The HTML

<div class="buttons">
  <a href="..." target="_blank" aria-label="Sign the pledge (opens in a new tab)">
    Sign the pledge
    <i class="fa-solid fa-up-right-from-square"></i>
  </a>
</div>

The aria-label is what a screen reader announces instead of the visible text — it's there so someone who can't see the little arrow icon still gets told "this link opens in a new tab" out loud. Both the icon and that spoken warning are tied to the same "open in a new tab" checkbox, so they always agree with each other; you'll never end up with the icon showing but the label not mentioning it, or vice versa.

The CSS

display: flex; flex-wrap: wrap; on the row means the buttons sit side by side and automatically drop onto a new line if they run out of horizontal space — no extra work needed for that to happen responsively.
