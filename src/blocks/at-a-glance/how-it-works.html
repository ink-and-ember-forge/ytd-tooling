Think of this like the little summary box you sometimes see at the top of a recipe, before the actual steps — a quick "here's what you're getting" before the reader dives into the page.

The HTML

It's just a box with a heading and a list:

<div id="at-a-glance">
  <h3 id="at-a-glance-heading">At a glance</h3>
  <ul>
    <li>Your bullet point</li>
  </ul>
</div>

The heading text "At a glance" never changes, so the tool writes it for you — one less thing to type or accidentally misspell. Each <li> is one bullet; add or remove as many as you like in the form and the tool builds the list to match.

The CSS

id="at-a-glance" is how the CSS finds this exact box to give it its grey background and the navy line underneath. border-radius: 20px 20px 0 0 means "round the top-left and top-right corners, leave the bottom two square" — that's why it looks like a rounded card sitting on a flat base.

li + li { margin-top: 10px; } means "add a gap above any bullet that comes right after another bullet" — the + is CSS-speak for "the one right after". That's why the first bullet sits flush at the top, but every bullet after it gets a bit of breathing room.

On mobile

order: 2 is like a seating chart that only applies on small screens — it tells this box "you're in seat 2" so it lands in the right spot (title, then this box, then the table of contents, then everything else) even though the actual HTML order underneath never changes.
