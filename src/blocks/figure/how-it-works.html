In 30 seconds: one image at the full width of the content column, with an optional caption underneath. Use it for charts, diagrams and tables that have to be read.

Why not Text around media?

That block floats its picture small (about 275px) beside the text, which makes a chart unreadable. This one is a block of its own: the image is as wide as the column and as tall as it needs to be.

Alt text

A figure carries information, so its alt text should say what it shows (for a chart, the main point). The tab warns you if it is empty. If a picture is only decoration, use Text around media instead and leave its alt blank.

Caption

Optional. It is a real <figcaption>, so assistive technology connects it to the image.

Deep dive: the code 
<figure class="figure-block">
  <img src="…" alt="…" />
  <figcaption>…</figcaption>
</figure>

The class is figure-block rather than figure, which Bootstrap already uses.
