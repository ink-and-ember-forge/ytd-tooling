In 30 seconds

An accordion is a list of titles that each hide a panel. Click a title and its panel slides open; open another and the first one closes.

It all hinges on one trick: every title and its panel share a name. The builder writes both names for you, from the same words, so they can never drift apart.

See it on your own accordion. Open the Explain tab beside the preview, then hover data-bs-target in the code and watch the matching names light up.

The idea: a button that knows its panel by name

Think of a filing cabinet: each drawer has a label, you click the label to slide the drawer open, and, because this is a well-behaved cabinet, opening one drawer closes whichever one was already open.

The button doesn't know what "Digital literacy" means. It only knows a name to look for, like dialling a phone number:

<button data-bs-target="#collapse-digital-literacy" ...>Digital literacy</button>

<div id="collapse-digital-literacy" ...>(your content goes here)</div>

The # means "the element with this id". Bootstrap's script (already loaded by the base HTML) finds the panel with that id and opens it.

What goes wrong when the names don't match

If the two names differ by even one letter, clicking the title does nothing at all, and there is no error message to tell you why. This is the most common way a hand-edited accordion breaks. It is why the builder writes both names from the same title: there is nothing to mistype.

"Only one open at a time"

Every panel also carries data-bs-parent="#accordion-…", naming the accordion it belongs to. Bootstrap reads that as an instruction: "when I open, ask every other panel in this group to close." No custom code is needed.

The "Group name" field

It only gives the whole accordion a readable name (for example accordion-digital-literacy-resources instead of a random one). It is for the humans who read the pasted code later and changes nothing about how it behaves.

Deep dive: what happens when you click a title
  1. You click the button. Because it has data-bs-toggle="collapse", Bootstrap's script takes over.
  2. It reads data-bs-target and looks up the element with that id.
  3. It adds the class show to the panel (the collapse class hides it otherwise) and removes collapsed from the button, which is what turns the arrow.
  4. It flips aria-expanded to "true", so screen readers announce that the panel is open.
  5. It reads data-bs-parent, finds the other panels in that group, and closes them the same way.

Our CSS only changes how this looks (the arrow, the underline, no borders). The behaviour is entirely Bootstrap's.
