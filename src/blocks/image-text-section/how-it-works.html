Picture a newspaper column with a photo tucked into the corner and the text flowing around it, wrapping underneath once it runs past the photo's height. That's exactly what this block does — except the "photo" can also be a video, or nothing at all.

The HTML

<div class="image-text-section">
  <img src="..." alt="..." />
  <div>
    (your content goes here)
  </div>
</div>

Two things sit side by side inside the wrapper: the image (or video, or nothing), and a <div> holding whatever you wrote in the rich text editor. Whatever formatting you used — headings, bullet points, plain paragraphs — gets carried straight through into that div as real HTML.

The CSS trick — floating

The image is told to float: right, which is an old but still very useful CSS trick: it pulls the image out to the right-hand side and lets everything else (the text in the div) flow around it like water round a rock, wrapping underneath once the image ends.

.image-text-section::after {
  content: "";
  display: block;
  clear: both;
}

This last bit is called a "clearfix" — without it, a floated image can spill outside its own box and overlap whatever comes after it on the page. This rule tells the browser "stop, don't let anything float past this point" — it's invisible, but it's what keeps the layout tidy underneath.

The "Large" image size

Choosing "Large" adds a media-large class to the image, which swaps its size (250px max normally, 340px/45% when Large) — this is how the old "badge" image style (like the pledge certificate graphic) got folded into this same block instead of being a separate one.
